# Youth Care NGO

A modern, emotionally calming, and visually premium website for the Hyderabad-based youth support initiative **Youth Care**. 

## Introduction
Youth Care is a sanctuary dedicated to guiding youngsters (primarily ages 15-30) out of contemporary dark struggles into mental clarity, spiritual peace, and lifework direction.

### Core Support Areas
- **Addiction Recovery**: Shame-free plans to break screen time, vaping, and negative habits.
- **Emotional Counseling**: Free, professional, and 100% confidential check-ins for anxiety, burnout, and depression.
- **Islamic Guidance**: Navigating struggles by connecting psychological strategies with timeless scriptural wisdom and prayers.
- **Youth Mentorship**: One-on-one elder mentorship programs to build supportive real-world habits.
- **Hyderabad Session Circles**: Segregated weekly gatherings held every Sunday evening in Murad Nagar for fellowship, strategy discussions, and dinner.

---

## Design & Aesthetics
- **Dark Cinematic Theme**: Matte black/charcoal UI panels to create a calming, non-intimidating user atmosphere.
- **Gold Accents**: Muted golden variables (`#c5a85c`) representing hope and spiritual warmth.
- **Responsive Layout**: Mobile-first design elements engineered to scale beautifully on any viewport size.
- **Subtle Motion**: Elegant page transitions and interactive micro-interactions powered by Framer Motion.

---

## Technology Stack
- **Framework**: React (Vite)
- **Styling**: Tailwind CSS v4 (native post-processing, config-free CSS variables)
- **Routing**: React Router DOM (with route-based layout wrappers)
- **Icons**: Lucide React
- **Animations**: Framer Motion

## Local Development Setup

1. **Clone the repository**:
   ```bash
   git clone https://github.com/syedmuzzamilali/yc_frontEnd.git
   cd yc_frontEnd
   ```

2. **Install dependencies**:
   ```bash
   npm install
   ```

3. **Start the local development server**:
   ```bash
   npm run dev
   ```
   Open `http://localhost:5173` to preview the website.

4. **Build for production**:
   ```bash
   npm run build
   ```
